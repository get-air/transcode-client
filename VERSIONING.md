# Versioning

`@get-air/transcode` follows Semantic Versioning while using `0.MINOR.PATCH`
before 1.0: increment `MINOR` for incompatible API or server-protocol changes,
and `PATCH` for compatible fixes and additions.

Stable releases use `vX.Y.Z` GitHub tags and are published from GitHub Releases.
Published versions are immutable. The optional `/video` integration declares the
compatible `@get-air/video` range explicitly.
